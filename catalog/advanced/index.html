Help and support

  • Search Tips

    Cultural Collections Search is a search-first discovery platform. These tips help you find records quickly and precisely across all collections.
  • Metadata and Fields

    Every record is described using a consistent set of metadata fields. Understanding these fields helps you interpret records and search more effectively.
  • Rights and Licensing

    Rights vary from item to item. Always check the rights statement on an individual record before reusing material.
  • Citing Collections

    Cite collection items so others can locate the exact record you used. Every item record provides the details you need to build a citation.
  • Access Restrictions Explained

    Records carry an Object Access Condition that tells you what you can do with the digital asset. Look for it on item records and result cards.
  • Frequently Asked Questions

    Answers to common questions about searching, downloading and using Cultural Collections Search.
  • Indigenous Cultural Data and Access

    How Cultural Collections Search supports the respectful management, description and discovery of Aboriginal and Torres Strait Islander cultural heritage, knowledge and collections.
  • Contact the Collections Team

    Submit an enquiry, request access to an item, or ask for further information from the Collections team.

Tips for better results

  • Rows: add rows to expand your search, or delete rows to simplify it.
  • Search fields: search a specific field (Title, Creator, Subject, Description) instead of everywhere.
  • Match type: each row can require its terms (Contains all), allow either (Contains any), or exclude them (Does not contain).
  • Filters: narrow by object type, collection, creator, licence, access and production date — each filter has its own Includes all (AND) / Includes any (OR) choice.
  • Use quotation marks to search for an exact phrase, e.g. "eucalyptus oil".

Search examples

  • All Fields → Contains all → eucalyptus oil bottle will display records with all three terms anywhere in the record.
  • Subject field → Contains all → botanical illustration will display records with botanical AND illustration in the subject field.
  • Subject field → Contains any → botanical illustration will display records with botanical OR illustration in the subject field.

Filter examples

  • Object Type → Includes all → Photograph, Manuscript will display records tagged with both Photograph AND Manuscript.
  • Object Type → Includes any → Photograph, Manuscript will display records tagged with either Photograph OR Manuscript.
